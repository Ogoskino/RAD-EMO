# Data access

[RAD-EMO on GitHub](https://github.com/Ogoskino/RAD-EMO) provides public collection
documentation, conceptual illustrations, aggregate metadata and small utilities.
The sensor dataset is being prepared for Zenodo under the reserved DOI
[10.5281/zenodo.23765400](https://doi.org/10.5281/zenodo.23765400).
Dataset files are not currently available for public download.

The main deposit covers recording-level images, radar measurements and supporting
metadata. A separate derived analysis companion contains prepared analysis inputs.
The original data management plan (DMP) names the NTU Data Archive as the
institutional preservation route. An addendum describing the linked Zenodo
deposit has been prepared for DMP review.

## Release and reuse conditions

The DMP requires deposit before the thesis is submitted for examination. Its
embargo for anonymised files ends when the final approved thesis is submitted
to IRep before degree conferment. This is a thesis milestone; a calendar date for
opening downloads has not been announced. The planned initial Zenodo deposit
uses restricted file access while these conditions apply.

Access to identifiable material remains subject to institutional restrictions.
Consent forms, participant contact details and linkage keys are excluded from the
dissemination package. The DMP specifies reuse for research purposes; the final
dataset licence and access instructions will accompany the archive record.

See [the Zenodo deposit overview](ZENODO.md) for the relationship between the
sensor dataset, derived companion and institutional preservation, and
[NTU's research data management guidance](https://www.ntu.ac.uk/m/library/supporting-researchers/research-data-management)
for the institutional framework.

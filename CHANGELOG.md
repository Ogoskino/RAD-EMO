# Change log

## Initial public documentation - 29 October 2026

- Prepared the standalone RAD-EMO collection documentation for
  [github.com/Ogoskino/RAD-EMO](https://github.com/Ogoskino/RAD-EMO).
- Described the 114-recording, 15-participant collection, its protocol conditions,
  reported-affect labels, sensor coverage and temporal alignment.
- Added generated conceptual figures, a directory guide, data dictionaries,
  aggregate metadata and manifest/checksum verification utilities.
- Established the recording-level sensor dataset as the primary archive scope,
  with derived analysis inputs described as a separate companion.
- Linked the reserved Zenodo DOI
  [10.5281/zenodo.23765400](https://doi.org/10.5281/zenodo.23765400)
  and documented the DMP's thesis-related access and research reuse conditions.

The Zenodo dataset deposit is in preparation. This entry records the initial
documentation milestone; a dataset release version has not yet been assigned.

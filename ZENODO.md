# Zenodo dataset deposit

The RAD-EMO sensor dataset is being prepared for Zenodo under the reserved DOI
[10.5281/zenodo.23765400](https://doi.org/10.5281/zenodo.23765400).
The deposit will bring together recording-level RGB and thermal images, radar
ADC measurements, acquisition tables, annotation exports, labels, timing
information and configuration. Modality coverage and available measurement
representations are described in [images and sensor recordings](RAW_DATA.md).

| Resource | Purpose |
| --- | --- |
| [GitHub documentation](https://github.com/Ogoskino/RAD-EMO) | Collection description, illustrations, schemas, utilities and archive links |
| Zenodo sensor dataset | Preserved recording-level images, sensor measurements and supporting metadata |
| Derived analysis companion | Separate processed features, waveform estimates, support masks and analysis manifests |
| NTU Data Archive | Institutional preservation route for the original collection specified in the data management plan |

The sensor collection is the primary dataset. The derived companion provides
prepared analysis inputs and will be described separately from the sensor files.
The [directory guide](docs/DIRECTORY_STRUCTURE.md) explains the proposed archive
layout and the contents of this documentation repository.

The release version, publication date and download links will be added when the
deposit is available. Access and research reuse follow the collection's data
management plan; see [data access](ACCESS.md). Creator and contributor details
are listed in [citation guidance](CITATION.md).

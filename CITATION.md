# Cite RAD-EMO

**Creator:** Ogonna Okafor, Nottingham Trent University.

**Dataset:** *RAD-EMO: Multimodal laboratory recordings of object carriage and
reported affect*.

**Reserved DOI:** [10.5281/zenodo.23765400](https://doi.org/10.5281/zenodo.23765400).
The Zenodo dataset deposit is in preparation; its release version and publication
date have not yet been assigned.

Maria Mwanje contributed to data collection and David Adama provided supervision,
both at Nottingham Trent University.

When the dataset is released, cite the Zenodo record and the version used.
The primary citation will describe the recording-level sensor collection.
Any separately released derived analysis companion will have its own citation
details. Cite associated methods papers separately where relevant.

Current documentation is maintained at
[github.com/Ogoskino/RAD-EMO](https://github.com/Ogoskino/RAD-EMO).
See [data access](ACCESS.md) for the deposit's access and reuse conditions.
